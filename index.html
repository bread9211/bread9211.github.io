FIELD NOTES / 001

What my first bridge taught me

A short reflection on testing a design before spending time polishing it.

Read note

The first bridge twisted under load before the joints gave way. Adding a diagonal brace made the next model feel steadier, but changing the brace and the joints together made it hard to tell which change mattered most. Next time, I’d keep the joints the same and test the brace on its own.

01 / STRUCTURES

Truss Bridge

A small span with a measurable failure point.

A basswood bridge built for an introductory design challenge. The team compared truss layouts, sketched the load paths, and added weight in steps to see where the model began to twist.

TOOLS Onshape · Basswood · Load testing

02 / ELECTRONICS

Room Monitor

Logging temperature and humidity at a desk.

An Arduino reads a temperature and humidity sensor and sends the readings to a computer. A Python script plots the data to show how placement near a window changes the measurements.

TOOLS Arduino · DHT22 · Python

03 / CAD & FABRICATION

Adjustable Stand

A desktop phone stand designed for 3D printing.

A two-piece stand with slots for different viewing angles. Test prints helped tune the fit of the tabs and leave enough clearance for a charging cable.

TOOLS Onshape · FDM printing · Calipers
